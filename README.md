# Python Course Flask Project

## Overview
This repository contains a small Flask application built during a Python backend course.
The purpose of this project was to understand Flask fundamentals such as routing,
templates, and basic CRUD operations.

## What I Learned
- Flask application structure
- Request/response lifecycle
- Basic CRUD with a relational database
- Template rendering with Jinja2

## Scope & Limitations
This is intentionally a small, beginner-level project and does not include
production features such as authentication, caching, or deployment.

## Note
More advanced backend work, including production-style APIs and scalable systems,
can be found in my other repositories.
